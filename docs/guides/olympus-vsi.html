On this page

Olympus VSI Viewer ​

Open the images Olympus and Evident cellSens save as .vsi: brightfield slides from a VS120 or VS200 scanner, and fluorescence, 16-bit, Z-stack and time series images. No cellSens, no Bio-Formats export, no upload. The viewer reads only the part you look at, so a large slide opens without a conversion step.

A VSI image is a .vsi file plus a folder next to it, named like the file with an underscore on each side: Image_00.vsi and _Image_00_. The pictures are in the folder. Keep both together.

How to Open a VSI File ​

  • A folder on your disk, in Chrome and Edge. Drop the folder that holds the .vsi file and its _name_ folder on the viewer. See Local Files.
  • One zip made without compression, in any browser, from your disk or its address. See Zip Without Compression.
  • An address of that zip: https://, s3:// or gs://. See Remote URLs.
  • Private data, with a private link or a token. See Private Images and Slides.

A .vsi file dropped on its own, or opened by its own link, cannot open, because the pictures are in the folder. The viewer says so and tells you what to do.

What You Will See ​

  • Brightfield slides (H&E and other stains) open as slides: zoom from the whole slide down to single cells. Tiles the scanner did not store show the slide's background colour.
  • Label and Macro. They appear under the title. Click one to enlarge it. A label may show patient details. The viewer shows it and never saves or sends it.
  • Fluorescence, 16-bit data, Z-stacks and time series open as microscopy images, with every channel by the name the file gives it. Sliders step through Z and time. A Z-stack can also be viewed in 3D. See 3D Rendering.
  • Several images in one file, such as a scan at 20x and another at 40x. Each scan is in the Series list. On a slide, the Label and Macro show as pictures under the title.
  • Compression. JPEG, JPEG 2000, lossless JPEG and uncompressed data.
  • Pixel size from the file, so measurements read in µm. To set your own, see Pixel Size and Magnification.

The viewer was checked against Bio-Formats on sample files from the VS120 and VS200 scanners and from the cellSens software: the regions it opened matched. JPEG 2000 pictures stay within one grey level of other decoders.

If a File Does Not Open ​

The viewer tells you why.

What you openedWhat the viewer says
A .vsi file without its folderA VSI image is a .vsi file and the folder _name_ beside it. Drop the folder that holds both, or a zip of them made without compression (zip -0 -r image.zip folder).
A .vsi file whose folder holds no image files, after an interrupted copyThe folder _name_ holds no image files. Copy it again from where the image was saved, then open the folder that holds both.
The link of a .vsi fileA VSI image opens from a link only as a zip of the .vsi file and its _name_ folder, made without compression (zip -0 -r image.zip folder).
A zip made with compressionThe files in this zip are compressed, so they cannot be read in parts. Unzip it and open the folder, or make the zip again without compression (zip -0 -r slide.zip folder).
A file with nothing the viewer can showThis file holds no image the viewer can show, followed by the reasons.

When one image of a file is left out and the others open, a notice reads "Not shown: image (reason)". For example: an extended focus image, 32-bit or other pixel types the viewer does not read yet, PNG, BMP or 16-bit JPEG tiles, spectral and phase series, a data file that is missing or damaged, or a colour image with several channels.

Confocal images from an Olympus or Evident FluoView FV3000 or FV4000 are saved as .oir instead. See the Olympus OIR Viewer.

Public VSI Files to Try ​

Download an image with its folder, then drop the folder on the viewer. Or make a zip without compression.

For Your IT Team ​

To open a zip by address, the server must answer byte-range requests and allow them through CORS. For a bucket, allow GET and the Range header in its CORS rules. What the Server Needs has the details.

Privacy ​

The file is read in your browser. Opening one counts as one opened image of the kind "Olympus VSI file". The file name and address are never recorded. See the privacy policy.
