Each opens from your disk, and most by their address too. A DICOM folder and a CZI plate saved as one file per field open by address as a zip. A zip made without compression is one file, so it opens in every browser, from your disk or its address. Which plate views each format gets: Plates at a glance. Details and limits are on each format's page. Which formats state their pixel size and magnification, and how to set them when a file does not: Pixel Size and Magnification.

Every plate opens in Field view, with the well navigator and the well picker. Plate view shows one field per well, and Well view every field of one well. OME-Zarr stores each field at lower resolutions too, so both views work at any plate size. CZI, Opera Phenix, Yokogawa and ImageXpress plates keep each field at one resolution, so a view opens when its full-size images fit in 256 MB. A small CZI plate gets all three views; on a 384-well JUMP plate, Well view is on and Plate view is off. Plate and Well view explains it. Convert a plate to OME-Zarr for Plate view at any size.

Every slide opens as a pyramid. A level the file does not store is made from the one above it, so zoom stays smooth. The label and macro show as thumbnails under the title; click one to enlarge it. A label may show patient details: the viewer shows it and never saves or sends it. The colour profile can be turned off in the side panel.

Annotations open with any slide from GeoJSON or OME-XML, and from the scanner's own files: Aperio ImageScope XML, Hamamatsu NDP.view .ndpa and ASAP XML. See Exchanging Annotations.

Companion data ​

  • Label masks that live outside the image: a Zarr label array from a URL, or from a folder in Chrome and Edge. See Labels.
  • Measurements and analysis bundles: a CSV or Parquet table with one row per object, up to a run manifest that lists several masks and tables, all from one URL. A table also opens from your disk in Chrome and Edge. See Analytics Data Format, and HCS Analytics in the Browser for a real screen.
  • Plate manifests: a small JSON file that describes an Opera Phenix, Yokogawa CellVoyager or ImageXpress plate. Save one from the viewer and open it by URL. The format is a published JSON Schema: plate-manifest/v1.json.

Which browser opens what ​

Files, zips and every address open in every browser. A folder from your disk needs Chrome or Edge. The full table is in Local Files.

A folder, a zip or several files with more than one image, and a file with several images inside open on a list with a picture of each, then a gallery under the image. See Folders, Zips and Series.

Not supported yet ​

Other vendor formats open after conversion to OME-Zarr. How to Convert Any Microscopy File to OME-Zarr shows how.
