On this page

Leica LIF Viewer ​

Open a .lif project from Leica LAS X with every image in it. Confocal Z-stacks, time series, tile scans and lambda scans from SP5, SP8 and Stellaris systems open as they are. No Fiji, no Bio-Formats export, no upload. A single image saved as .lof opens too, and so does a project exported as an XLEF folder.

How to Open a LIF File ​

  • One file on your disk, in any browser. Drop it on the viewer, or click Open Image and Choose File. See Local Files.
  • A folder of LIF files, in Chrome and Edge. One file opens, several show a list, including files one folder down. See Local Files.
  • An address: https://, s3:// or gs://, or a Zenodo file link that ends in /content. Paste it under Open Image. See Remote URLs.
  • Private data, with a private link or a token. See Private Images and Slides.

The viewer reads only the parts it shows. A 3 GB project opens in a few requests, and pictures arrive as you look at them.

What You Will See ​

  • Every image of the project. The Series list names each one by its place in the project, such as FRET_AB_423_001/Bleach003. Folders are not listed.
  • Channels. Colours come from the LUT each channel was recorded with in LAS X.
  • Lambda scans. Each wavelength is a channel, named by its wavelength, such as 420 nm, and drawn in the colour of its wavelength, from violet to red. Turn channels on and off to compare them.
  • Z and time. Sliders step through the planes, in the order they were recorded. A Z-stack can also be viewed in 3D. See 3D Rendering.
  • Tile scans, stitched. The tiles are placed where the stage recorded them, and a later tile covers an earlier one where they overlap. When LAS X also saved its own stitched copy, the Merged image, it is listed next to the tile scan. LAS X aligns tiles when it merges, so where you need seamless edges, open the Merged image.
  • 8, 12 and 16-bit data. 12-bit images open with their full range.
  • Pixel size and Z step from the file. To set your own, see Pixel Size and Magnification.

LAS X stores each image at one resolution. The viewer makes the lower resolutions itself, so zooming out stays smooth.

If an Image Is Not Shown ​

A project can hold images the viewer cannot show yet. The others open, and a note names what was left out:

What the image hasWhat the viewer says
One plane of all channels over 256 MBtoo large to open without a pyramid. Convert it to OME-Zarr to open it here.
A lambda scan of several channelsa lambda scan of several channels, which the viewer does not open yet.
An excitation lambda scan, or another axishas a spectral (λ) axis, which the viewer does not show yet.
A tile scan stored mirrored or turneda tile scan stored mirrored or turned. Open its Merged image instead, if the project has one.
Float or 32-bit samples32-bit data, which the viewer does not read yet.

When no image of a project can be shown, the file does not open, and the note lists every reason. Convert it to OME-Zarr to open a very large image with every resolution.

LOF Files ​

LAS X can save one image on its own as a .lof file (Leica Object File). It opens like a project with one image: drop it on the viewer, choose it under Open Image, or paste its address. The image keeps the name it has in LAS X. What the viewer cannot show yet is the same as for a LIF, in the table above.

XLEF Folders ​

LAS X can also export a whole project as a folder: an .xlef file, a Metadata folder, and the images as .lof or .tif files. In Chrome or Edge, drop that folder on the viewer, or click Open Image and Choose Data Folder. It opens like a LIF project, with every image in the Series list. A zip of the folder made without compression opens too.

  • Drop the whole folder. The .xlef file alone holds no pixels, so the viewer asks for its folder.
  • Images exported as compressed TIF files do not open yet.
  • From your disk only. The address of an .xlef file does not open the project.

What the viewer cannot show yet is the same as for a LIF, in the table above.

Public LIF Files to Try ​

  • Project007.lif: confocal Z-stacks of a neuron and a 2 x 2 tile scan with its Merged image. Peter Zentis, Zenodo 6606445, CC BY 4.0.
  • AMR1.lif: 3 GB, 12-bit, five channels, three tile scans with their Merged and processed copies. Pamela Young, Zenodo 15353569, CC BY 4.0.
  • Convalaria_LambdaScan.lif: a lambda scan of Convallaria from a STELLARIS 8, 29 wavelengths from 420 to 700 nm. Maria Manuela Azevedo, Zenodo 14976703, CC BY 4.0.

For Your IT Team ​

To open a file by address, the server must answer byte-range requests and allow them through CORS. For a bucket, allow GET and the Range header in its CORS rules. What the Server Needs has the details.

Privacy ​

The file is read in your browser. Opening one counts as one opened image of the kind "Leica LIF file". The file name and address are never recorded. See the privacy policy.
