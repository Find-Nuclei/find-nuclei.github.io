On this page

Zeiss CZI files ​

Find Nuclei Viewer opens Zeiss CZI files, the format ZEN writes. Nothing is converted and nothing is uploaded. The viewer reads the file by byte range and decodes only the pieces you look at, so a large file starts showing before it is downloaded.

Other formats the viewer opens are listed in Supported Formats. Plates from other instruments have their own guides: Opera Phenix Plates and Yokogawa CellVoyager Plates.

Opening a CZI from the web ​

Click Open Image on the landing page, paste the address of the .czi file into the URL field and click Load from URL. An https:// address and an s3:// address both work.

https://zenodo.org/api/records/7015307/files/W96_B2+B4_S=2_T=1=Z=1_C=1_Tile=5x9.czi/content

s3://your-bucket/your-folder/your-file.czi

The viewer reads the start of the file, then the index of the file, then the pixels. It never downloads the whole file to open it.

Opening a CZI from disk ​

Drop the .czi file on the viewer. A folder of CZI files works too: see Plates saved as one file per field. Or click Open Image, go to the Local Files tab and click Choose File. This works in every browser, Chrome, Edge, Firefox and Safari alike, because a CZI is one file. Nothing leaves your computer.

What opens ​

  • Z-stacks, time series and channels. The viewer shows every plane and moves through Z and T. Z-stacks open in 3D too.
  • Scenes. A file with several scenes opens as a series. Pick a scene from the Series dropdown.
  • Extra dimensions. Illumination, view, phase, rotation and block open as a list to choose from. When a file has one such dimension and one scene, the list is named after it, for example Illumination. Each entry shows only its own images.
  • Mosaics. Tiled images are stitched on the fly, at the positions ZEN recorded.
  • Stored pyramids. When ZEN saved lower resolutions, the viewer uses them. Zooming out stays fast.
  • Celldiscoverer 7 and other well plates. A CZI with a plate layout opens as a plate, in Field view, with the well navigator and the well picker. See HCS Plates.
  • Compression. Uncompressed, Zstd and JPEG XR files open. Whole-slide scans saved with JPEG XR open when ZEN stored a pyramid.
  • Pixel types. 8-bit and 16-bit grayscale, and 8-bit and 16-bit RGB.

Channel colours come from ZEN's display settings, the same colours you see in ZEN. When a file has no pixel size, it opens at scale 1 and the Image Information dialog says so.

Plates ​

A plate in a CZI stores each field at one resolution. So, like an Opera Phenix plate, it opens in Field view only. The note under the Field | Well | Plate toggle says so, and Learn more opens this guide. Want plate and well overviews? Convert the file to OME-Zarr. The Opera Phenix guide explains why.

The viewer follows the plate rules of czitools. When a file has scenes but no usable plate layout, it opens as a series of scenes and the info line says why.

An Example Gallery tile, Zeiss CZI, opens a real plate with one click. Plates saved as one file per field are described below.

Plates saved as one file per field ​

Some instruments write every field of a plate to its own CZI file. IDR idr0011 is an example. The viewer puts those files back together as one plate, in the plate view.

From a folder. Drop the folder on the viewer. Or click Open Image, go to the Local Files tab and click Choose Data Folder. Folders open in Chrome and Edge. The plate opens in Field view, with the well navigator and the well picker. In Firefox and Safari, use the zip.

From a zip. Zip the folder without compression, then drop the .zip on the viewer, click Choose File on the Local Files tab, or paste its web address. Choose File is for a single file or a zip. Choose Data Folder is for a folder. The viewer reads the zip by byte range, so it never downloads all of it.

zip -0 -r plate.zip folder

The -0 matters. It stores the files as they are, which lets the viewer read each CZI in parts. A compressed zip is refused with a message that says so.

How the plate is built. Wells come from the metadata in each file, never from the file name. Fields in a well follow the time they were acquired. Wells may hold different numbers of fields, and each well shows only its own.

One folder, several things. When a folder or zip holds more than one thing, a list titled Choose a dataset appears. Each row is one thing. Pick a row to open it.

  • A plate. The row shows how many fields and wells it holds.
  • An image. A single file. When a file is set apart from its plate, its row says why. For example: its channels, size, Z, T or pixel size differ from the rest of the plate; it has the same well and position as another file, taken later; its well lies outside the plate; or its well name does not match its row and column.
  • A file that cannot be read. The row is greyed out and shows the reason, such as "Not a CZI file." or "Part of a split file."

A folder with exactly one thing opens without the list.

One field alone. Open a single field file and it opens as one field. The viewer tells you: "This file is one field of a plate. Drop the whole folder to see the plate." Opened by address, it points you to a zip of the folder instead.

Like every CZI plate, these open in Field view only. See Plates above.

What does not open yet ​

A file the viewer cannot read is refused with a message that names the file and says what to do. These are the messages.

CaseMessage
JPG, LZW or another compressionThis CZI file uses a compression the viewer cannot read yet (JPG). In ZEN, save a copy without compression or with Zstd, and open that.
32-bit float and other pixel typesThis CZI file stores Gray32Float pixels. The viewer reads 8-bit, 16-bit and RGB images.
Channels with different pixel typesThis CZI file mixes pixel types across channels (Gray8, Gray16). The viewer cannot show them together yet.
A large mosaic with no stored pyramidThis scene is a large tiled image with no lower resolutions stored, so the viewer cannot show it yet. In ZEN, save a copy with a pyramid, and open that.
A plate with an extra dimension, such as rotation or phaseThis CZI plate has more than one phase (2). The viewer cannot show that dimension on a plate yet.
A file still open in ZENThis CZI file was not closed by ZEN, so it may be incomplete. Open it in ZEN and save it again.
A file split into partsThis CZI file is split into parts. The viewer opens single-file CZI only.
A zip with compressed CZI files{zip}: The CZI files in this zip are compressed, so they cannot be read in parts. Make the zip without compression (for example zip -0 -r plate.zip folder) and open that.
A very large indexThis CZI file is too large to open without an index. An index for large files is planned.
Not a CZIThis file is not a CZI file.

Saving a copy in ZEN. Most refusals share one fix. In ZEN, save a copy of the file without compression or with Zstd. Open that copy. For a big mosaic, save it with a pyramid.

Big mosaics. A tiled scene wider or taller than 3000 pixels needs stored lower resolutions. Without them the viewer would have to read every tile to draw one screen. A scene with a single tile per plane always opens.

Other tools. If you use Bio-Formats, it converts a CZI to OME-Zarr. The conversion guide shows how. Large mosaics, such as Axioscan slide scans, need the stored pyramid described above.

Hosts ​

Opening by address needs a server that answers byte-range requests and allows them through CORS. Some public data servers do. These are tested:

  • Zenodo, API links. Use the form https://zenodo.org/api/records/<id>/files/<name>/content. It works.
  • Zenodo, download links. A link that ends in ?download=1 does not. The server sends no CORS headers, so a browser cannot read it. Switch to the API form above.
  • Your own bucket. Allow GET and the Range header in the bucket's CORS rules. Remote URLs has the details.

When a server cannot send parts of a file, the viewer says so. Download the file and open it from your disk.

A public server that rate-limits requests may slow down a large mosaic, because each tile is a request.

Public CZI files to try ​

  • Zenodo. Opens by address with the API link ending in /content. Try record 10577186 and record 11234863. Both are CC BY 4.0.
  • OpenSlide test data. Zeiss folder, CC0, with files in several compressions. The server answers byte ranges but sends no CORS headers. Download a file and drop it on the viewer.
  • Bio-Formats sample images. Zeiss-CZI folder. The same applies: no CORS headers, so download a file first.

For other places to find public data, see Remote URLs.

Privacy ​

The viewer reads the file in your browser. Opening a CZI counts as one opened image of the kind "Zeiss CZI file". The file name and address are never recorded. See the privacy policy.
