On this page

Aperio SVS slides ​

Find Nuclei Viewer opens Aperio SVS files, the whole-slide format of Aperio scanners. Nothing is converted and nothing is uploaded. The viewer reads the file by byte range and decodes only the tiles you look at, so a large slide starts showing before it is downloaded.

Other formats the viewer opens are listed in Supported Formats. A sibling guide covers another slide and plate format: Zeiss CZI Files.

Opening an SVS from the web ​

Click Open Image on the landing page, paste the address of the .svs file into the URL field and click Load from URL. An https:// address and an s3:// address both work.

https://your-server.example.com/slides/slide.svs

s3://your-bucket/your-folder/slide.svs

The viewer reads the start of the file, then its directory of images, then the tiles. It never downloads the whole file to open it.

Opening an SVS from disk ​

Drop the .svs file on the viewer. Or click Open Image, go to the Local Files tab and click Choose File. Opened files appear under Recent. Nothing leaves your computer.

Drop a folder that holds .svs files and the viewer says: "Drop one SVS file to open it." Pick one file from the folder and drop that.

What opens ​

  • The slide. One image, in 2D, with its resolutions. Zooming out stays fast.
  • Label and Macro. When the file holds the label photo or the macro photo, they appear under the title. Click one to enlarge it. A label may hold patient details. It is shown here and never saved or sent by the viewer. For a file on a server, your browser reads it from that server like the rest of the file.
  • Compression. Slides with JPEG tiles and slides with JPEG 2000 tiles (the Aperio codes 33003 and 33005) open.

What does not open yet ​

A file the viewer cannot read is refused with a message that names the file and says why.

CaseMessage
A file over 4 GB (BigTIFF)This SVS file is larger than 4 GB. The viewer cannot read it yet.
Another compressionThis SVS file uses a compression the viewer cannot read yet (LZW).
Not 8-bit RGB (grey, 16-bit or more than three channels)This SVS file is not 8-bit RGB. The viewer cannot read it yet.
Not stored in tilesThis SVS file is not stored in tiles. The viewer cannot read it yet.
Not an Aperio fileThis file is not an Aperio SVS file.
A damaged or incomplete fileThis SVS file looks damaged or incomplete.

A TIFF whose description does not mention Aperio is refused too. Other whole-slide formats open after conversion to OME-Zarr. How to Convert Any Microscopy File to OME-Zarr shows how.

Browsers ​

An SVS is one file, so it opens from disk or by address in Chrome, Edge, Firefox and Safari alike.

Safari decodes JPEG tiles with its own decoder, so pixel values differ slightly from Chrome and Firefox. Use Chrome or Firefox for pixel measurements.

Hosts ​

Opening by address needs a server that answers byte-range requests and allows them through CORS. For your own bucket, allow GET and the Range header in its CORS rules. Remote URLs has the details.

When a server cannot send parts of a file, the viewer says so. Download the file and open it from your disk.

Public SVS files to try ​

OpenSlide publishes test slides: Aperio folder. They are CC0, with JPEG and JPEG 2000 files. The server sends no CORS headers, so a browser cannot read them by address. Download a file and drop it on the viewer.

For other places to find public data, see Remote URLs.

Privacy ​

The viewer reads the file in your browser. Opening an SVS counts as one opened image of the kind "Aperio SVS file". The file name and address are never recorded. See the privacy policy.
