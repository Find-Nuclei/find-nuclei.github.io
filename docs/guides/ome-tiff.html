OME-TIFF Viewer ​

Open OME-TIFF files in your browser, with all their channels, Z planes and time points. The viewer reads only the part you look at, so a large file opens without reading all of it first.

Open Example OME-TIFFOpen It in 3DOpen Your Own Data

The example is a Z-stack of 67 planes. Free. Nothing to install. Your file stays on your computer.

How to Open an OME-TIFF File ​

Working with many files?

Several files chosen together, or a zip of them, open as a gallery in every browser. A whole folder opens in Chrome and Edge on a computer, not in Firefox and Safari.

  • One file on your disk, in any browser. Drop it on the viewer, or click Open Image and Choose Files. See Local Files.
  • A folder of files, in Chrome and Edge. One file opens. Several show a list with a picture of each. After you pick one, a gallery of pictures under the image takes you to the next. See Folders, Zips and Series.
  • An address: https://, s3:// or gs://. Paste it under Open Image. See Remote URLs.
  • Private data, with a private link or a token. See Private Images and Slides.

A Z-stack can also be viewed in 3D, whichever of these it was opened from. See 3D Rendering.

What You Will See ​

  • Lower resolutions. When the file has them, zooming out stays fast.
  • Channels. Names and colours come from the file. RGB and multi-channel fluorescence both open.
  • Z and time. Sliders step through the planes.
  • 3D. A Z-stack opens in 3D too, with XY, XZ and YZ planes and the volume. See 3D Rendering.
  • Pixel types. 8, 16 and 32-bit integers and float.
  • Compression. None, LZW, Deflate, PackBits, JPEG and JPEG 2000.
  • Pixel size and magnification. The pixel size comes from the file, and the magnification from the objective it names. To set your own, see Pixel Size and Magnification.

If a File Does Not Open ​

The viewer tells you why.

What the file hasWhat the viewer says
Planes kept in other filesThis OME-TIFF keeps its planes in other files. The viewer reads one file for now.
Another compression, such as ZstdThis OME-TIFF uses a compression the viewer cannot read yet.
Another pixel type, such as doubleThis OME-TIFF has a pixel type the viewer cannot read yet.
Not an OME-TIFFThis file is not an OME-TIFF.
A damaged or incomplete fileThis OME-TIFF looks damaged or incomplete.

Label and overview images are left out, with a note.

Annotations ​

Import GeoJSON or OME-XML, and export both, from the Annotations panel. Send a link that opens the slide with its annotations. Exchanging Annotations shows how. To draw, measure and label shapes on the slide, see Annotations.

Public Files to Try ​

The OME project publishes sample OME-TIFF files, with pyramids under sub-resolutions.

For Your IT Team ​

To open a file by address, the server must answer byte-range requests and allow them through CORS. For a bucket, allow GET and the Range header in its CORS rules. What the Server Needs has the details.

When a server cannot send parts of a file, the viewer says so. Download the file and open it from your computer.

Addresses that start with s3:// and gs:// work too.

Privacy ​

The file is read in your browser. Opening one counts as one opened image of the kind "OME-TIFF file". The file name and address are never recorded. See the privacy policy.
