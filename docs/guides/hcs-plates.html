HCS Plates ​

Find Nuclei Viewer supports High-Content Screening (HCS) plate data in OME-ZARR format — any plate format including 96, 384, 1536-well, and custom layouts.

Opening a Plate ​

Open an HCS plate the same way as any other OME-ZARR dataset — drag and drop or paste a URL. The viewer automatically detects plate metadata and adjusts the interface.

Navigation Levels ​

HCS plates have three viewing levels:

Field View ​

When a plate first loads, you see the first field of the first populated well. This is the same as viewing a regular single image — zoom, pan, adjust channels.

Grid View ​

Click Show All Fields to see all fields in the current well arranged in a grid. This gives you a spatial overview of the entire well.

Plate View ​

Click Show Full Plate to see the full plate layout. All populated wells are rendered as a grid, showing a preview of each well's content.

Well Navigation ​

In Plate View, click any well to jump to it. The viewer zooms into that well's fields.

Seamless Zoom ​

The signature feature: zoom smoothly from the full plate overview all the way down to individual cells. The viewer handles multi-resolution tile loading across wells and fields transparently.

Channel Controls ​

Channel settings (colors, contrast, visibility) apply across all wells and fields simultaneously. Change a channel color once and it updates plate-wide.

Labels on Plates ​

Segmentation labels can be loaded at the plate level. The viewer discovers shared label names across wells and renders them consistently.
